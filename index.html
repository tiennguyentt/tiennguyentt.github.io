01 / AI-Native

I did not adopt an AI tool. I built the agent system that runs the product function and kept the sign-off.

I built a PM system on Claude using Karpathy's LLM Knowledge Base pattern. Transcripts auto-compile into a structured wiki, conflicts resolve against a truth hierarchy, and every spec is graded before it reaches engineering. Each correction is fed back, so the bar rises with use. I stay the one who reads the diff and signs off.

  • Transcript to structured wiki. Raw meeting transcripts and notes auto-compile into a living knowledge base, so the spec starts from what was actually said, not from memory.
  • Truth-hierarchy conflict resolution. When sources disagree, the system ranks them by evidence and flags the contradiction instead of silently picking one.
  • Automated spec grading and health checks. Each requirement is graded for clarity, source coverage, and acceptance criteria before it ships, and compounding corrections raise the bar over time.
  • Agent skills and subagents. Purpose-built Claude Code skills and subagents draft BRDs, FRDs, and tickets. I run the same loop to build my own products end to end.
